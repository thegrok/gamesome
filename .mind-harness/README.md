# .mind-harness

This folder is the repository execution surface for Gamesome. The workspace vault remains
authoritative for Actions and canonical specs.

## For agents

1. Read the supplied Action/spec and `agent-context.md` before working.
2. Treat `specs/` and `agent-logs/` as preserved project history and working context.
3. Record factual discoveries in `findings/` when the task calls for them.
4. Append repo-scoped execution notes to `changelog.md` when appropriate.

Do not edit a workspace-supplied `deployed-spec.md`; it is a convenience copy.
